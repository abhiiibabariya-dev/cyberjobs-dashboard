    About this snapshot

    The data on this page comes from dashboard_jobs.json, a file produced by cyberjobs-dashboard — a Python scanner that crawls LinkedIn for SOC and security roles. This page is a static viewer hosted on GitHub Pages: it can display whatever data is in that JSON file at build time, but it cannot run live scans, accept logins, or apply on your behalf. Those features live in the Flask app in the same repository and require running it locally.

    Updates to this page require pushing a new dashboard_jobs.json to the gh-pages branch. Listings shown here are not endorsements; verify any role against its source link before applying.

    Built as a static viewer for the cyberjobs-dashboard project. No tracking. No login. No backend.
