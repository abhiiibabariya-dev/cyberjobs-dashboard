    About this snapshot

    The data comes from dashboard_jobs.json, produced by cyberjobs-dashboard — a Python scanner that crawls LinkedIn for SOC and security roles. This page is a static viewer hosted on GitHub Pages. Saved jobs, applied state, hidden listings, and resume text live only in localStorage on this browser — nothing is sent to any server.
